# Troca de domínio (arquivado)

Este passo a passo era pro modo produção do Clerk, que precisava de domínio próprio.
Desde 27/11/2026 o login é o Neon Auth, que não precisa de domínio. Domínio próprio agora é só opcional (endereço mais bonito):
basta apontar o domínio pra Vercel e adicionar o endereço em **trusted domains** do Neon Auth.
